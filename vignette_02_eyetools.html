2. Analýza pomocí balíku eyetools (Tidyverse)

Author

Antigravity

Published

December 3, 2025

Úvod

Balík eyetools poskytuje sadu funkcí pro zpracování a vizualizaci eyetrackingových dat. V této vignetě si ukážeme, jak využít jeho analytické funkce, ale výsledky vizualizovat pomocí ggplot2 pro větší flexibilitu.

1. Příprava dat

eyetools vyžaduje specifické názvy sloupců: pID, trial_values, time, x, y.

# Načtení našich vygenerovaných dat
raw_data <- read.csv("data/raw_data.csv")
et_data <- raw_data %>%
  rename(
    pID = subject_id,
    trial = trial_id,
    experiment_time = time,
    time = timestamp,
  ) %>%
  select(pID, trial, time, x, y)
aoi_sets <- read.csv("data/aois.csv") %>%
  select(x, y, width_radius = width, height)
aoi_names <- read.csv("data/aois.csv") %>%
  pull(aoi_name)
