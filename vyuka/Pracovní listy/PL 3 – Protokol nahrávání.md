# PL 3 – Protokol nahrávání brýlemi

Účastník (kód): ..............   Datum: ..............   Brýle / čočky: ano / ne

## Role

| Role | Kdo | Co dělá |
| --- | --- | --- |
| Účastník | | má brýle, plní úkoly |
| Experimentátor | | ovládá nahrávání, čte pokyny, říká „start“ a „konec“ |
| Zapisovatel | | měří čas stopkami od spuštění nahrávání, vyplňuje tento list |
| Kontrolor | | sleduje živý náhled a zapisuje, kdy pohled „ujel“ nebo se ztratil |

Po každém účastníkovi se role posunou.

## Před nahráváním

- [ ] Brýle sedí pevně, účastník je pohodlně otočí hlavou do stran.
- [ ] Účastník stojí na značce 1 m od zdi. Změřená vzdálenost očí od zdi: ............ cm
- [ ] Kalibrace proběhla. Počet pokusů: ......
- [ ] Kontrola: pohled v náhledu sedí na prstu experimentátora.  ano / ne
- [ ] Nahrávání běží a stopky jsou spuštěné ve stejnou chvíli.

## Úkol 6: počítání zpaměti

Účastník se celou dobu dívá na tečku na prázdné zdi a nemluví, dokud nezná výsledek. Postup u každého příkladu: **3 sekundy ticha → experimentátor přečte příklad → účastník počítá potichu → řekne výsledek → 5 sekund pauza.**
